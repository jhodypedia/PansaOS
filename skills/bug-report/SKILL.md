# Bug report

Pastikan target dan ruang lingkup yang diizinkan sebelum pengujian. Tulis judul konkret, lingkungan, prasyarat, langkah reproduksi minimal, expected/actual behavior, dampak, dan bukti. Hindari klaim severity tanpa dasar. Redaksi secret dan data pribadi dari screenshot/log. Sertakan rekomendasi perbaikan dan langkah retest. Jangan submit atau mengirim laporan ke pihak lain tanpa approval.
