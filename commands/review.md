description: Review changes and findings since the last checkpoint
---
Laporkan status kerja sejak checkpoint terakhir. Wajib tepat tiga bagian:

1. Perubahan: pakai checkpoint_changes pada checkpoint terakhir; sebut path dan status (changed/added/deleted). Jangan menghitung ulang atau mengarang hash.
2. Git (bila repo): sebut hanya hasil nyata git_status dan git_diff. Bila git gagal karena bukan repo, tulis persis itu dan jangan menyimpulkan apa pun soal history.
3. Temuan dan belum diverifikasi: bug konkret dengan path/baris bila ada, risiko, dan apa yang belum dijalankan.

Jangan mengubah file. Jangan menyatakan test lulus tanpa output asli.
